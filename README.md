# 👑 Youplix WhatsApp Session Generator (SilvaTech Style)

Yeh standalone Web App bilkul **https://session.silvatech.co.ke/** jaisi hai! 
Is se aapko aik **Permanent 24/7 Free HTTPS Link** milta hai jo aap dunya ke kisi bhi bande ko WhatsApp par bhej sakte hain.

---

## 🚀 Render.com Par 100% Free 2-Minute Me Deploy Karein:

1. **[Render.com](https://render.com)** par free account banayein (Google / GitHub se login karein).
2. Dashboard par **"New +"** ➔ **"Web Service"** select karein.
3. Apni GitHub repository connect karein (ya yeh folder upload karein).
4. Settings me sirf yeh daalein:
   - **Name:** `youplix-session`
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
5. **"Create Web Service"** (Free Instance) par click karein!

---

## 🎉 Aapka Permanent Public Link Ready Ho Jayega:
👉 `https://youplix-session.onrender.com`

### 📱 Yeh Link Kaise Use Karein:
1. Yeh link kisi bhi bande ya client ko WhatsApp par bhejein.
2. Wo link kholega, apna WhatsApp number daal kar **8-digit code** nikaalega.
3. Code apne WhatsApp me lagate hi **Session ID** uske WhatsApp DM me deliver ho jayegi aur screen par bhi aa jayegi!
4. Wo aapko Session ID send karega.
5. Aap apne bot ke `config.json` me:
   ```json
   "sessionId": "YOUPLIX~xxxxxxxxxxxxxxxxxx"
   ```
   daal kar bot start kar dein! Zero QR scan, zero camera zaroorat!
